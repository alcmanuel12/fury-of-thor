# <div align="center">🎬 **Cinematic Overview**</div>

> Deep within a forgotten Nordic forest, a circle of runes glows faintly beneath the whisper of pines.
> Each rune carries the name of a warrior—
> a friend, a teammate, a developer.
>
> When the lightning strikes,
> **Thor chooses.**
>
> No favoritism, no bias.
> Only thunder, chaos, and JavaScript.

**Fury of Thor** is a creative, collaborative front-end project designed as a gamified selection ritual.
It showcases:

* Polished UI/UX
* Modular architecture
* Mobile-first engineering
* Pixel-art aesthetics
* Interactive animations
* Professional sound design

All wrapped in a humorous but elegant Norse theme.

# <div align="center">🌩️ **Core Features**</div>

### 🎮 **Interactive Ritual Gameplay**

* Dynamic rune circle
* Lightning-driven selection
* Breaking runes animation
* Random prophecy messages
* Thor enters “furious mode” during sacrifice

### 🎨 **Pixel-Art Aesthetic**

* Nordic forest background
* Wooden UI panels
* Runic iconography
* Custom bubble speech styling

### 🔊 **Sound Engine**

* Forest ambience
* Ritual soundtrack
* Lightning SFX
* Mute button with replaceable icon states

### 📱 **Fully Reimagined Mobile Experience**

Not just responsive:
**custom-designed layout for 360×800**:

* Recentered rune circle
* Scaled bubble
* Repositioned controls
* Adapted animations
* Safe areas & readability improvements

### ⚙️ **Modular Architecture**

Each screen operates independently:

```
src/
├── core/

├── ui/
│   ├── screens/
└── main.js 
```

This structure ensures maintainability, readability, and scalability.

# <div align="center">📁 Project Structure</div>

```
fury-of-thor/
├── public/
├── src/
│   ├── assets/
│   │   └── fonts/
│   ├── core/
│   ├── css/
│   ├── ui/
│   │   ├── screens/
```

**Structure Overview:**

- **`public/`** - Public assets and entry point HTML
- **`src/core/`** - Core game logic (state management, persistence, runes, sound)
- **`src/ui/`** - User interface components
  - **`screens/`** - Individual screen modules (home, player selection, ingame, credits)
  - UI utilities (alert popup, runes circle, typewriter, vikings list)
- **`src/css/`** - Stylesheet
- **`src/assets/`** - Static assets (fonts)

Simple, clean, modular.
